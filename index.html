ダウンロード

パソコン（Windows / Mac）で行います。設定・基準姿勢・記録したデータは消えません。

書き込み方

  1. 上の「ダウンロード」を押して、HangOff-v○○.uf2 を保存します。
  2. 受信機やサーボの電源（5V）を XIAO から外し、XIAO を USB ケーブルでパソコンにつなぎます。充電専用ではなく、データ通信ができるケーブルを使ってください。
  3. XIAO の USB 端子の横にある小さなリセットボタン（RST）を、素早く2回押します。LED がゆっくり明るくなったり暗くなったりし、パソコンに XIAO-SENSE という USB メモリのようなドライブが現れます。
  4. 保存した .uf2 ファイルを、そのドライブにドラッグ＆ドロップ（コピー）します。
  5. コピーが終わると XIAO が自動で再起動し、ドライブは消えます。「ディスクが正しく取り出されませんでした」と出ても問題ありません。
  6. このページで「接続」を押し、上の「本体（接続中）」が最新の版になっていれば完了です。
うまくいかないとき
  • ドライブが出ない: 2回押す間隔をもっと短くしてみてください。別の USB ケーブルや USB 端子も試してください。
  • コピーしても版が変わらない: ドライブが出た状態でコピーしたか確認してください。普通の状態の XIAO には書き込めません。
  • スマホしかない: この方法はパソコンが必要です。

● 未保存の変更があります

基準姿勢がまだ記録されていません。バイクをまっすぐ立てて止め、「基準姿勢を記録」を押してください。

基準姿勢: バイクをまっすぐ立てて止めた状態で押し、約1秒動かさずに待ちます。そのときの姿勢を 0° とし、ジャイロのゼロ点も測って本体に保存します（そのとき他の設定も一緒に保存されます）。

変更はすぐ反映されますが、「本体に保存」を押さないと電源を切ったときに元に戻ります。
